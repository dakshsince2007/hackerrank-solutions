# Technique   dictionary-mapping-fixed-unpacking
# Time        O(N)
# Space       O(N)
# Insight     The implementation maps student names to lists of scores and calculates the average by unpacking exactly three elements from the list associated with the query name.
# Interview   Before: "I should iterate through the dictionary and sum all elements dynamically." After: "Since the problem constraints imply exactly three marks per student, I can unpack the list into three variables to calculate the average in O(1) time after O(N) dictionary construction."
# Pitfalls    (1) The code assumes exactly three marks per student, which will raise a ValueError if the input contains a different number of scores.  (2) The code fails to handle students not present in the dictionary because it lacks an else block for the query_name check.
# ──────────────────────────────────────────────────

if __name__ == '__main__':
    n = int(input())
    student_marks = {}
    for _ in range(n):
        name, *line = input().split()
        scores = list(map(float, line))
        student_marks[name] = scores
    query_name = input()
    if query_name in student_marks:
        x,y,z=student_marks[query_name]
        a=f"{((x+y+z)/3):.2f}"
        print(a)
